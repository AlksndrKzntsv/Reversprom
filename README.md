# Реверспром

Сайт компании «Реверспром» — промышленный реверс-инжиниринг: восстановление деталей и узлов по образцу,
3D-сканирование, конструкторская документация, проектирование оборудования.

**https://reverseprom.ru**

## Что внутри

```
site/          сайт: одна страница index.html (HTML, CSS и JS без сборки и зависимостей),
               политика обработки персональных данных privacy.html, изображения Pictures/
function/      обработчик формы заявки — функция Yandex Cloud Functions на Python (только стандартная библиотека)
docs/          развёртывание (DEPLOY.md) и инструкция для тестировщиков (README_TEST.md)
deploy.sh      публикация сайта в Yandex Object Storage
```

Форма заявки принимает файлы до 10 МБ (фото, PDF, STEP/STL, DWG/DXF, архивы). Браузер загружает их напрямую
в закрытый бакет по временным подписанным ссылкам, функция прикладывает их к письму и удаляет из хранилища.

## Локальный запуск

```bash
python3 -m http.server 8080 -d site
```

Откройте http://localhost:8080/

## Публикация

Сайт размещён в Yandex Cloud (Object Storage, Cloud DNS, Certificate Manager). Публикация:

```bash
./deploy.sh --dryrun   # показать изменения
./deploy.sh            # опубликовать
```

Настройка окружения и инфраструктуры — в [docs/DEPLOY.md](docs/DEPLOY.md).
