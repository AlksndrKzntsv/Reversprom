## Тест лендинга «Реверспром»

В архиве:
- `index.html` — страница
- `Pictures/` — изображения (не удаляйте и не переименовывайте папку)

### Онлайн-версия (GitHub Pages)

Лендинг опубликован в репозитории GitHub и доступен по ссылке:

**https://zandrey501-star.github.io/Reversprom/**

Репозиторий: **https://github.com/zandrey501-star/Reversprom**

Это самый удобный способ для теста коллегам — достаточно открыть ссылку в браузере, без распаковки архива и без локального сервера. Форма заявки отправляет данные в собственную функцию Yandex Cloud (см. `DEPLOY.md`) и работает без VPN; при открытии `index.html` двойным кликом (`file://`) отправка может не работать.

При каждом обновлении в ветке `main` сайт автоматически пересобирается через GitHub Actions.

### Как открыть локально

#### Вариант A (рекомендуется): через локальный сервер
1) Откройте терминал в папке с файлами.
2) Запустите:

```bash
python3 -m http.server 8080
```

3) Откройте в браузере:
- `http://localhost:8080/`

#### Вариант B: двойной клик по `index.html`
Обычно работает, но некоторые браузеры/настройки могут ограничивать внешние запросы (форма, загрузка файлов).

### Что тестировать
- Форма заявки: имя/контакт/комментарий
- Прикрепление файлов в форме (до 10 файлов, общий размер до 10 МБ; фото, PDF, STEP/STL, DWG/DXF, архивы) и успешная отправка — письмо приходит на рабочие адреса с вложениями
- Отказ при попытке прикрепить файл больше 10 МБ или недопустимого типа (например, `.exe`)
- Блок «Примеры работ» (открытие модалки «Было / Стало»)
- Альтернативная отправка через Telegram (показывается, если отправка заявки не удалась)

## Скрипты генерации логотипа (в корне репозитория)

> Копия для архива также лежит в папке `reversprom-landing-test/`.

### `generate_logo.py` — генерация логотипа через OpenAI

Скрипт создаёт **4 варианта логотипа «РЕВЕРСПРОМ»** с помощью модели `gpt-image-1` (OpenAI Image API):

| Файл | Формат | Фон |
|------|--------|-----|
| `logo_reversprom_horizontal_white.png` | горизонтальный (1536×1024) | белый |
| `logo_reversprom_horizontal_dark.png` | горизонтальный (1536×1024) | тёмный |
| `logo_reversprom_square_white.png` | квадратный (1024×1024) | белый |
| `logo_reversprom_square_dark.png` | квадратный (1024×1024) | тёмный |

**Запуск:**

```bash
cd /путь/к/Reversprom
pip install -r requirements.txt
cp .env.example .env   # вставьте OPENAI_API_KEY
python3 generate_logo.py
```

Ключ API берётся из файла `.env` (в репозиторий не попадает).

Каждый вариант генерируется **отдельно**, поэтому буквы и стиль могут немного отличаться между файлами.

### `make_logo_variants.py` — варианты из готового логотипа (без перерисовки)

Скрипт берёт уже сгенерированный файл `logo_reversprom_horizontal_dark.png` и создаёт **точные** производные версии (те же буквы, без повторной генерации ИИ):

- `logo_reversprom_horizontal_white_exact.png` — горизонтальный на белом фоне (тёмный металл)
- `logo_reversprom_square_white_exact.png` — квадратный на белом (ПРОМ под ЕВЕРС)
- `logo_reversprom_square_dark_exact.png` — квадратный на чёрном (светлый металл)

**Запуск:**

```bash
cd /путь/к/Reversprom
pip install -r requirements.txt
python3 make_logo_variants.py
```

Требуется библиотека **Pillow**. Исходник `logo_reversprom_horizontal_dark.png` должен лежать в той же папке.
