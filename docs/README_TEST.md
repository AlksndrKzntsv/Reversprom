## Тест сайта «Реверспром»

Файлы сайта — в папке `site/` репозитория:
- `index.html` — страница сайта
- `privacy.html` — политика обработки персональных данных и текст согласия
- `Pictures/` — изображения: 3D-модели, фото готовых изделий, чертёж (не удаляйте и не переименовывайте папку)

### Онлайн-версия

Сайт опубликован по адресу **https://reverseprom.ru/**

Репозиторий: **https://github.com/AlksndrKzntsv/Reversprom**

Форма заявки отправляет данные в собственную функцию Yandex Cloud (см. `docs/DEPLOY.md`) и работает без VPN; при открытии `index.html` двойным кликом (`file://`) отправка может не работать.

Сайт обновляется не автоматически: после изменений его публикуют командой `./deploy.sh`. Если правка уже в репозитории, но на сайте её нет — значит, её ещё не опубликовали.

### Как открыть локально

#### Вариант A (рекомендуется): через локальный сервер
1) Откройте терминал в папке репозитория.
2) Запустите:

```bash
python3 -m http.server 8080 -d site
```

3) Откройте в браузере `http://localhost:8080/`

#### Вариант B: двойной клик по html-файлу
Обычно работает, но некоторые браузеры/настройки могут ограничивать внешние запросы (форма, загрузка файлов).

### Что тестировать
- Форма заявки: имя/контакт/комментарий (в комментарии тестовых заявок пишите «тест»)
- Прикрепление файлов в форме (до 10 файлов, общий размер до 10 МБ; фото, PDF, STEP/STL, DWG/DXF, архивы) и успешная отправка — письмо приходит на рабочие адреса с вложениями
- Без галочки согласия на обработку персональных данных заявка не отправляется (браузер просит её отметить); ссылки в тексте согласия открывают `privacy.html` в той же вкладке, кнопка «Вернуться к заявке» возвращает к форме с сохранёнными данными
- Отказ при попытке прикрепить файл больше 10 МБ или недопустимого типа (например, `.exe`)
- Блок работ: по нажатию на карточку открывается просмотр всех фото проекта; листание стрелками на экране и клавишами ←/→, закрытие кнопкой «×», клавишей Esc и нажатием на фон
- Раздел «Проектирование оборудования» (`#design`): 9 карточек, по нажатию открывается просмотр материалов проекта
- Бегущая строка под первым экраном; в блоке «Как мы работаем» при прокрутке слева меняется фото и подсвечивается текущий этап (на телефоне фото показаны внутри этапов); на этапе «3D-сканирование» сначала видно фото детали, через ~1 с луч за ~8 с проходит сверху вниз и деталь превращается в чертёж; при уходе с этапа и возврате сканирование начинается заново (на телефоне — когда картинка появляется на экране)
- Отображение на телефоне (ширина ~390 px): нет горизонтальной прокрутки, меню и кнопки не наезжают друг на друга
- Альтернативная отправка через Telegram (показывается, если отправка заявки не удалась)
