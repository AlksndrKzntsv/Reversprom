# CLAUDE.md

Этот файл содержит инструкции для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Обзор проекта

Одностраничный сайт компании «Реверспром» (промышленный реверс-инжиниринг) — https://reverseprom.ru/ — и серверный обработчик заявок с формы. Тексты для пользователей, комментарии и документация — на русском языке; придерживайтесь этого.

Сборки, линтера и тестов в проекте нет. Репозиторий на GitHub публичный.

## Структура

```
site/          всё, что публикуется на сайте: index.html, privacy.html, Pictures/
function/      index.py — обработчик формы для Yandex Cloud Functions
docs/          DEPLOY.md (развёртывание сайта, функции, DNS и почты), README_TEST.md (инструкция для тестировщиков)
deploy.sh      публикация site/ в бакет Object Storage
models/        исходники моделей от конструктора (STEP/STL/SLDPRT) — в .gitignore, не публиковать
logotips/      рабочие материалы логотипа — в .gitignore
```

В `site/` не кладите ничего, что не должно быть публичным: `deploy.sh` загружает папку целиком.

## Команды

```bash
# Локальный запуск (предпочтительнее, чем открывать index.html через file:// — там может не работать форма и загрузка файлов)
python3 -m http.server 8080 -d site      # → http://localhost:8080/

# Публикация сайта (нужен AWS CLI с профилем reverseprom, см. docs/DEPLOY.md)
./deploy.sh --dryrun                     # показать, что изменится
./deploy.sh                              # загрузить
```

## Архитектура

- **`site/index.html`** — весь сайт: встроенный CSS, разметка (первый экран «чертёж + готовое изделие» с бегущей строкой, задачи, этапы `#process` с закреплённым экраном и сменой фото, услуги `#services`, технические возможности, работы `#works`, проектирование оборудования `#design` (рендеры проектов конструктора в `Pictures/Projects/<Проект>/NN.jpg`), FAQ `#faq`, форма заявки `#contact`) и встроенный `<script>` в конце (этапы при прокрутке и анимация «фото → чертёж» на этапе сканирования — `Planetary Gear drawing.png`, просмотр фото проекта по набору `WORK_SETS`, форма заявки). В форме обязательная галочка согласия на обработку ПДн со ссылками на **`site/privacy.html`** (политика и согласие; реквизиты оператора и e-mail для обращений `info@reverseprom.ru` заполнены, текст должен проверить юрист). Изображения подключаются относительными путями `Pictures/<Изделие>/…`; не переименовывайте эту папку и файлы в ней без правки HTML. Сторонние фото — в `Pictures/Stock/`, источники и лицензии указаны в docs/README_TEST.md. Абсолютный адрес сайта `https://reverseprom.ru/` прописан в canonical, og:url, og:image и schema.org. Контакты: `info@reverseprom.ru`, Telegram `t.me/reverseprom_ru`, MAX.
- **Работа формы заявки** (в два шага, т.к. запрос к функции ограничен 3,5 МБ): если есть файлы, скрипт в `index.html` отправляет на `LEAD_ENDPOINT` `{action: "init"}` со списком файлов, получает временные ссылки и загружает файлы напрямую в бакет `reversprom-leads` (PUT); затем отправляет `{action: "submit"}` с имя/контакт/комментарий и ключами файлов. Лимиты `MAX_BYTES` (10 МБ), `MAX_FILES`, `ALLOWED_EXTENSIONS`. Скрытое поле `website` — ловушка для ботов. `LEAD_ENDPOINT` — адрес развёрнутой функции (`https://functions.yandexcloud.net/d4ehb99eogd2b8r79s6m`). При сбое страница предлагает запасной вариант через Telegram.
- **`function/index.py`** — обработчик для Yandex Cloud Functions (`handler(event, context)`, python312): на `init` выдаёт подписанные (SigV4, реализовано вручную) ссылки на загрузку в `leads/<uploadId>/<n>`, на `submit` скачивает файлы из бакета, отправляет письмо с вложениями по SMTP и удаляет файлы. Только стандартная библиотека. Настройки — исключительно из переменных окружения: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `TO_EMAILS`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `ALLOWED_ORIGIN` (CORS, можно через запятую). `MAX_TOTAL_BYTES`, `MAX_FILES`, `ALLOWED_EXTENSIONS` должны совпадать с одноимёнными константами в `index.html`. Ошибки SMTP/S3 пишутся только в лог функции. Правки начинают действовать только после загрузки новой версии функции в консоли Yandex Cloud.
- **docs/README_TEST.md** — инструкция для тестировщиков; обновляйте её при изменении сайта или обработчика формы.

## Публикация и инфраструктура (Yandex Cloud)

- Сайт — бакет Object Storage `reverseprom.ru` в режиме «Веб-сайт», `www.reverseprom.ru` — бакет-переадресация. HTTPS — сертификат Let's Encrypt из Certificate Manager. Публикуется вручную через `./deploy.sh`, push в GitHub сайт **не** обновляет.
- DNS домена — зона в Cloud DNS (регистратор — reg.ru). В зоне же записи почты Яндекс 360 (MX, SPF, DKIM `mail._domainkey`, DMARC); не удаляйте их при правках DNS.
- Адреса сайта должны быть разрешены в `ALLOWED_ORIGIN` функции и в CORS бакета `reversprom-leads`.
- Никогда не коммитьте `.env` и ключи доступа (`~/.aws/credentials` — вне репозитория).
