# CLAUDE.md

Этот файл содержит инструкции для Claude Code (claude.ai/code) при работе с кодом в этом репозитории.

## Обзор проекта

Одностраничный лендинг компании «Реверспром» (промышленный реверс-инжиниринг), а также Python-скрипты для генерации логотипа и серверный обработчик заявок с формы. Тексты для пользователей, комментарии и документация — на русском языке; придерживайтесь этого.

Сборки, линтера и тестов в проекте нет.

## Команды

```bash
# Локальный запуск лендинга (предпочтительнее, чем открывать index.html через file:// — там может не работать форма и загрузка файлов)
python3 -m http.server 8080          # → http://localhost:8080/

# Python-скрипты (локально есть venv/; зависимости: openai, python-dotenv, pillow)
pip install -r requirements.txt
python3 generate_logo.py             # нужен OPENAI_API_KEY в .env (см. .env.example)
python3 make_logo_variants.py        # только Pillow, без обращений к API
```

## Архитектура

- **`index.html`** — весь сайт целиком: встроенный CSS, разметка (секции: первый экран, услуги `#services`, работы `#works`, FAQ `#faq`, форма заявки `#contact`) и один встроенный `<script>` в конце страницы (вкладки, модальное окно «Было / Стало», форма заявки). Изображения подключаются из `Pictures/<Изделие>/…png`; не переименовывайте эту папку и файлы в ней без правки HTML.
- **Работа формы заявки** (в два шага, т.к. запрос к функции ограничен 3,5 МБ): если есть файлы, скрипт в `index.html` отправляет на `LEAD_ENDPOINT` `{action: "init"}` со списком файлов, получает временные ссылки и загружает файлы напрямую в бакет Yandex Object Storage (PUT); затем отправляет `{action: "submit"}` с имя/контакт/комментарий и ключами файлов. Лимиты `MAX_BYTES` (10 МБ), `MAX_FILES`, `ALLOWED_EXTENSIONS`. Скрытое поле `website` — ловушка для ботов. Сейчас `LEAD_ENDPOINT` — заглушка `REPLACE-ME`, и отправка завершается ошибкой, пока адрес не задан. При сбое страница предлагает запасной вариант через Telegram (`t.me/reversprom_eng`).
- **`index.py`** — обработчик для Yandex Cloud Functions (`handler(event, context)`, python312): на `init` выдаёт подписанные (SigV4, реализовано вручную) ссылки на загрузку в `leads/<uploadId>/<n>`, на `submit` скачивает файлы из бакета, отправляет письмо с вложениями по SMTP и удаляет файлы. Только стандартная библиотека. Настройки — исключительно из переменных окружения: `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD`, `TO_EMAILS`, `S3_BUCKET`, `S3_ACCESS_KEY`, `S3_SECRET_KEY`, `ALLOWED_ORIGIN` (CORS, можно через запятую). `MAX_TOTAL_BYTES`, `MAX_FILES`, `ALLOWED_EXTENSIONS` должны совпадать с одноимёнными константами в `index.html`. Ошибки SMTP/S3 пишутся только в лог функции. Развёртывание (бакет, CORS, жизненный цикл, сервисный аккаунт, функция) — пошагово в **`DEPLOY.md`**; функция разворачивается в Yandex Cloud отдельно, не через GitHub Pages.
- **Скрипты логотипа**: `generate_logo.py` через OpenAI `gpt-image-1` создаёт четыре файла `logo_reversprom_{horizontal,square}_{white,dark}.png` (каждый генерируется независимо, поэтому они немного отличаются). `make_logo_variants.py` строит точные варианты `*_exact.png` из `logo_reversprom_horizontal_dark.png` путём отделения фона и перекомпоновки, без повторной генерации.
- **`reversprom-landing-test/`** (и `.zip`) — упакованная копия лендинга для тестировщиков. Это снимок, автоматически с корневым `index.html` не синхронизируется.
- **README_TEST.md** — инструкция для тестировщиков; обновляйте её при изменении обработчика формы или скриптов логотипа .

## Публикация

`.github/workflows/pages.yml` при каждом push в `main` публикует **весь корень репозитория** как есть на GitHub Pages (https://alksndrkzntsv.github.io/Reversprom/). Всё, что закоммичено в корень, становится публично доступным — никогда не коммитьте `.env` (он уже в `.gitignore`).
